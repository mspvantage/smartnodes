Decentralised VPN · open source · test network

A VPN where nobody, not even
the network, can tie you to what you do.

SmartNodes is a VPN run by many independent operators and coordinated by its own blockchain. You pay with anonymous tickets, your traffic crosses two nodes that never learn both ends, and it can look like an ordinary visit to a well-known website, so it works where VPNs are blocked.

What makes it different

Pay without being known

You buy tickets once; they are signed blind, so when a node is paid, nobody (not the node, not the issuers, not anyone reading the chain) can tell which purchase, or which person, a ticket came from.

Two hops, split knowledge

The entry node sees your address but not what you visit; the exit node sees what you visit but not who you are. They are run by different operators and paid separately, at times that cannot be lined up.

Works where VPNs are blocked

Entry nodes can disguise the connection with Xray REALITY, so it looks like a visit to a real website. A censor that checks finds that website. When WireGuard is blocked, the app switches over by itself.

Bridges a censor cannot list

Bridges are entry nodes on no public list. Each line costs a ticket and goes to a few people, so collecting them is slow and expensive. Bridges that give out rubbish lose part of their bond, and dead lines are reported and replaced.

Nodes are checked, not trusted

Independent probers, assigned at random, test each node through real paid sessions and report sealed results. Nodes that fail are hidden; nodes caught tampering lose bond. Operators cannot pick their own judges.

Nothing to log

Node software keeps sessions in memory only, refuses to start where it could write them to disk (in strict mode), and records only totals. It is built so an operator has nothing useful to hand over.

Where things stand

SmartNodes is being built in the open. Everything below has been built and tested on a private test chain; none of it has carried real value or real users yet.
