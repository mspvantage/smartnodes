Install

There are no apps yet: today SmartNodes runs on Linux, from the command line. Apps for Windows, macOS, Android and iPhone come later.

The programs

ProgramWho needs itWhat it does
smartvpnUsersThe VPN client: connects through two hops, buys and uses bridges, flags bad nodes.
smartnodeNode operatorsRuns an entry, exit or bridge node.
smartnodesdEveryone who talks to the chainThe chain itself, and the command line for chain transactions and queries.
smartprobeProbersTests the nodes the chain assigns, and reports results.
ticketctlTest network onlyMakes test ticket wallets and test issuer keys. It must never be used for anything of value.

What you need

  • A 64-bit Linux machine with root access and a kernel from 5.6 on, which has WireGuard built in.
  • Only to build from source: Go 1.26 or newer, and git.
  • For the client and nodes: wireguard-tools, iproute2 and iptables. The kernel's built-in WireGuard is used.
  • For the disguise and bridges: Xray.
  • jq and curl, which the examples use.
sudo apt update
sudo apt install -y git wireguard-tools iproute2 iptables jq curl

Download a release

Each release has ready-made programs for Linux on Intel/AMD and ARM, with checksums.

export VERSION={net:release}
export ARCH=$(dpkg --print-architecture)      # amd64 or arm64
cd /tmp
curl -fLO {repo}/releases/download/$VERSION/smartnodes_${VERSION}_linux_${ARCH}.tar.gz
curl -fLO {repo}/releases/download/$VERSION/SHA256SUMS
sha256sum -c --ignore-missing SHA256SUMS
mkdir -p ~/smartnodes-release
tar -xzf smartnodes_${VERSION}_linux_${ARCH}.tar.gz -C ~/smartnodes-release --strip-components=1
sudo install -m 0755 ~/smartnodes-release/bin/* /usr/local/bin/

Check: sha256sum prints OK. The release also holds Cosmovisor and the service files (in ~/smartnodes-release/deploy). All releases are on the releases page.

Or build from source

git clone {repo}.git
cd smartnodes
go build -o bin/ ./cmd/...
sudo install -m 0755 bin/* /usr/local/bin/

This needs Go 1.26 or newer, and takes a few minutes the first time.

Install Xray

Only needed for the disguise, bridges and probing disguised nodes. Download the Linux release for your machine from the Xray releases page, check its checksum, and put the xray program in /usr/local/bin:

unzip Xray-linux-64.zip xray
sudo install -m 0755 xray /usr/local/bin/xray
xray version

Check it worked

smartnodesd version
smartvpn          # prints its commands
smartnode -h      # prints its options

Updating

Download the new release as above, with its version in VERSION. If you build from source: git pull, then build and install again.

Restart any running node or client afterwards. While the network is in testing, an update can change the chain's rules, and the test chain may be restarted from scratch.
